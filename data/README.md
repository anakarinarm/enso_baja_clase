# Datos

Guarda aquí los archivos de datos utilizados por tu proyecto.

Para el minicurso trabajaremos con archivos como:

```text
sst_baja_1981_2026.nc
oni_mensual_1981_2026.csv
precipitacion_ensenada_1981_2026.csv
```

El contenido de esta carpeta está incluido en `.gitignore`, por lo que los datos
**no se subirán a GitHub**.

Esto es intencional: en proyectos científicos los datos pueden ser grandes,
tener otra fuente oficial de distribución o requerir reglas distintas de acceso.

El `README.md` principal del proyecto debe describir de dónde provienen los datos
y cómo obtenerlos.
